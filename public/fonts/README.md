# FoodGuard Kai Typeface

The user chose a general Kai-style typeface instead of the unlicensed STKaiti
font. This application bundles LXGW WenKai Regular v1.522 under SIL OFL 1.1.
It does not redistribute any Windows or Office font.

Official source:
https://github.com/lxgw/LxgwWenKai/releases/tag/v1.522

Source asset: LXGWWenKai-Regular.ttf (25,575,676 bytes).
Web asset: LXGWWenKai-Regular-v1.522.woff2 (8,016,756 bytes).
License and copyright notices: OFL-LXGW-WenKai.txt in this directory.

The WOFF2 file was compressed with FontTools 4.66.1 and Brotli 1.2.0 without
subsetting or removing glyphs. It is used only as a local web font, including
inside the Android WebView, not as an installable desktop font.

The CSS family alias is FoodGuard Kai. Normal text uses the original regular
weight; browser-synthesized bold provides heading emphasis. Preloading and
font-display: swap keep the interface usable during initial decoding.
