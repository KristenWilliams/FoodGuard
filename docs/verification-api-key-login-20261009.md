## 本次耗时样本

- `gpt-6-luna` 短文本连接测试约 1.3 秒；`gpt-6.1-sol` 约 1.7 秒。
- 软糖图片快速分析约 15 秒，深度分析约 61-66 秒。
- 最后的真实深度请求约 66 秒完成，首段响应约 16 秒收到，检测到四段保活数据。

这些是少量样本，不代表平均耗时或速度保证。保活只降低等待连接中断风险，不加速模型推理，也不延长上游请求期限。代理自身有独立超时限制，参见 [Cloudflare 524 官方说明](https://developers.cloudflare.com/support/troubleshooting/http-status-codes/cloudflare-5xx-errors/error-524/)。

## 未验证与边界

- 未在中国大陆三大运营商移动网络或多家国产手机的省电策略下测试。
- 强停后的系统调度和任务清理可能短暂滞后；不能保证强停、重启或网络断开后仍完成分析。
- 模型连接测试仅验证文本接口，不保证用户手选模型支持图片。
- 用户历史只存本机；上游 AI 的留存和现有代理的临时缓冲不属于应用层零存档保证。
- 未实现支付、开票、账号注册、额度或到期管理；由上游 Key 管理这些权限。未向 GitHub 发布，也未设置正式发布签名。
